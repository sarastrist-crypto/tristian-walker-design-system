commit bf9014d45ade16baacab07829c784448d19073c6 (v4.8.0, 2026-05-16).

They are a CLI-generation toolkit. To actually run them, install the
`printing-press` binary on your local machine:

    go install github.com/mvanhorn/cli-printing-press/v4/cmd/printing-press@latest

Requires Go 1.26.3 or newer. The binary is NOT installed in this repo.

See `printing-press/SKILL.md` for the main entry skill, and the upstream
README for usage and licensing.
